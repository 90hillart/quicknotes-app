QuickNotes is a simple note-taking web app that allows users to create, organize, search and delete personal, work and study notes. Notes are saved in the browser using localStorage so they remain available after refreshing the page.

## Features

- Add notes
- Categorize notes as Personal, Work or Study
- Delete notes
- Search notes
- Validate note length
- Display note count
- Show note creation date and time
- Save notes using localStorage
- Responsive layout for smaller screens

## How to run locally

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

You can also use the Live Server extension in Visual Studio Code.
